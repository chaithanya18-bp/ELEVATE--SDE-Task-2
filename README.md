
# CredVault – Certificate Management System

## About
CredVault is a web-based Certificate Issuing and Verification Platform developed for Elevate Skills SDE Task 2.

## Features
- User-friendly home page
- Certificate application form
- Automatic Application ID generation
- Track application status
- Verify certificates
- Admin login
- Manage applications
- Manage certificates
- Download certificates as PDF

## Technologies Used
- HTML
- CSS
- JavaScript

## How to Run
1. Download or clone this repository.
2. Open index.html in a web browser.
3. Use the CredVault application.

CredVault makes certificate application, management and verification simple and convenient.
